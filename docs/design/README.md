# Desain UI/UX — Nacova Sablon (Sprint 1–2)

Desain antarmuka **Sistem Manajemen Operasional Sablon Nacova** untuk cakupan **Sprint 1–2** (`35 / 76` poin selesai), dipisah antara tampilan **Desktop (`1280px`)** dan **Mobile (`360px`)** dengan tema *Warm Workshop Editorial UI* (`Instrument Sans` + `JetBrains Mono`).

## Tautan & Berkas
- **Figma Live (Editable Auto-Layout + 22 Color Variables)**: [Nacova Sablon — Sprint 1–2 (Desktop & Mobile)](https://www.figma.com/design/x5gSN6yQRWvB4R4JKasgs1)
- **Berkas `.fig` lokal**: [`nacova-sprint-1-2.fig`](./nacova-sprint-1-2.fig)
- **Web Produksi (Sprint 1–2)**: [https://rpl.nawf.dev](https://rpl.nawf.dev)

## Cakupan Layar (17 Frame)
- **Design System (1 frame + 1 komponen)**: Palet warna, tipografi, komponen tombol/badge/alert, cakupan sprint, dan `Nacova/BrandMark`.
- **Desktop `1280px` (8 layar)**:
  - **Sprint 1**: `D-S1-01 Login`, `D-S1-02 Absensi Harian`, `D-S1-03 Data Pelanggan`, `D-S1-04 Kelola Karyawan (OWNER)`
  - **Sprint 2**: `D-S2-01 Dashboard Ringkasan`, `D-S2-02 Stok Bahan Sablon`, `D-S2-03 Mutasi Stok & Opname`, `D-S2-04 Rekap Absensi & Form Izin`
- **Mobile `360px` (8 layar)**:
  - **Sprint 1**: `M-S1-01 Login`, `M-S1-02 Absensi Harian`, `M-S1-03 Data Pelanggan`, `M-S1-04 Kelola Karyawan (OWNER)`
  - **Sprint 2**: `M-S2-01 Dashboard Ringkasan`, `M-S2-02 Stok Bahan Sablon`, `M-S2-03 Mutasi Stok & Opname`, `M-S2-04 Rekap Absensi & Form Izin`
